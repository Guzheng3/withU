WithU 安卓端对接 API 文档

覆盖「情侣空间」与「共同观影」全部接口 · 面向安卓端 App 开发者
主服务 withU（PHP）· 媒体库 withUstrm（Java 8081）

1. 基础信息

1.1 Base URL

安卓端一般只对接主服务，统一使用主服务地址：

http://<主机IP>:8088

所有接口路径以 /api/ 开头：

GET  http://<主机IP>:8088/api/home.php
POST http://<主机IP>:8088/api/desktop.php?action=login

媒体库直连服务（可选，高级用法）：http://<主机IP>:8081/api

1.2 通用响应格式

系统没有统一的 {code,msg,data} 结构，多数接口以 success 布尔字段作为成功标志，错误信息在 message：

// 成功
{"success": true, "items": [...], "page": 1}

// 失败
{"success": false, "message": "评论内容不能为空"}

旧接口（home/albums/messages/comment/upload_*）与新型接口（travel*/watch/desktop/strm/douban_chart/cz/like）均以 success 判断，结构一致。

状态码含义
200成功
400参数错误 / CSRF 校验失败
401未登录
403无权限（非情侣账号角色）
404资源不存在
405方法不允许
429请求过于频繁（限流）
500 / 502服务器错误

1.3 认证机制（重要）

系统采用 PHP Session + Cookie 认证。安卓端实现要点：

  1. 登录：POST /api/desktop.php?action=login，JSON {"username":"...","password":"..."}。成功后服务端 Set-Cookie 下发 PHPSESSID（会话）与 withu_device（10 年信任设备），并在响应中返回 csrf_token 与用户信息。
  2. Cookie 持久化：必须实现 Cookie 存储（OkHttp CookieJar / WebView CookieManager），后续所有请求自动携带，重启 App 后自动恢复登录态。
  3. CSRF：所有写操作（POST/PUT/DELETE）必须携带 CSRF token，二选一：请求头 X-CSRF-Token: <csrf_token>，或请求体 _token 字段。token 来自 bootstrap/login 响应的 csrf_token；若收到 400「请求已过期」，重新拉 bootstrap 换新。
  4. 角色限制：影视/旅行/共看等功能要求角色 user1/user2，否则 403。

1.4 请求体类型

接口范围请求体
新接口（travel/media/watch/desktop/strm/like）JSON body（application/json）
旧接口（comment/article_chat/upload）表单（application/x-www-form-urlencoded）
上传接口multipart/form-data

3. 情侣空间 API

3.1 首页聚合 GET /api/home.php

无需登录（加密内容对游客隐藏），无参数。

{
  "success": true,
  "love_start_date": "2020-01-01",
  "stats": {"articles": 12, "events": 3, "albums": 5, "messages": 20},
  "articles": [{"id","title","nickname","avatar","created_at_text","is_encrypted","can_view_content","excerpt"}],
  "albums": [{"id","name","display_name","is_encrypted","created_at_text","description","image_count","nickname","avatar","images":["url"]}],
  "latest_messages": [{"id","nickname","avatar","content","time_ago"}]
}

3.2 相册列表 GET /api/albums.php

无需登录（未登录时加密相册不返回真实预览图）。参数：page（默认 1）、per_page（默认 3，最大 30）。

{"success", "page", "per_page", "has_more",
 "items":[{"id","user_id","name","is_encrypted","created_at","description","image_count",
           "nickname","avatar","is_co_created",
           "images":[{"src","type":"image"|"video"}]}]}

3.3 留言列表 GET /api/messages.php

无需登录（登录用户额外可见自己的私密留言）。参数：page、per_page（默认 6，最大 50）。

{"success","page","per_page","has_more","items":[{"id","nickname","avatar","content_html","time_ago","location"}]}

3.4 点赞 / 取消 POST /api/like.php

登录/游客均可。JSON + CSRF。

字段类型必填说明
target_typestring是article / album / event
target_idint是目标 ID

响应：{"success", "liked": bool, "count": int}

3.5 发表评论 POST /api/comment.php

登录/游客均可（游客必填 QQ + 昵称）。表单 + CSRF（_token）。

字段类型必填说明
article_idint三选一文章评论
album_idint三选一相册评论
event_idint三选一事件评论
parent_idint否回复评论时填
contentstring是≤100 字符
qqstring游客自动生成 qlogo 头像
guest_nicknamestring游客游客昵称
guest_avatarstring否游客头像

限流：登录 10 秒 1 条，IP 每小时 30 条。响应：{"success","message","comment_id"}

3.6 文章聊天块（情侣共创对话文章）

权限一致：需登录 + CSRF，且必须是作者或另一半（有共同编辑权限）。

端点方法参数说明
/api/article_chat_send.phpPOSTarticle_id(必填)、speaker(male/female/system)、type(text/image/video)、content(必填)发送对话块；限流 2 秒 1 条 / IP 60 次每分；返回 {success, block:{id,index,speaker,html}}
/api/article_chat_revoke.phpPOSTarticle_id、block_id（均必填）撤回对话块；返回 {success:true}
/api/article_blocks_sort.phpPOSTarticle_id、blocks_json（[{"id":1,"index":0}]）调整顺序；返回 {success:true}

4. 共同观影 API

4.1 共看房间 GET|POST /api/watch.php

需情侣账号。action 从 GET/POST/body 读取；房间号从 room/room_code 读取。POST 写操作需 JSON + CSRF。

action方法参数响应 / 行为
listGET无{success, items:[...]} withUstrm 媒体列表（分页首屏）
createPOSTmedia_id(必填){success, room_code, room_id, history_id}
defaultPOSTmedia_id(可选)加入/创建固定房 "WithU Watch"；另一半在线请求换片时返回 {choice_required:true, ...}
choosePOSTchoice(together/solo)、media_idtogether→join 默认房；solo→创建独立房
end_togetherPOST无{success, mode:"solo"}
joinPOST/GETroom code加入房间成员表
heartbeatPOST无{success, server_now_ms}
stateGETsince(可选)房间全量状态
pollGETsince(必填>0)增量事件轮询（≤20 条）
eventPOST见下上报播放/语音事件

state / poll 响应结构：

{
  "success": true, "mode": "together", "server_now_ms": 123456,
  "room": {"code","media_id","file_name","series_name","episode_number","episode_title",
           "url","player_mode","player_code","cover_url","duration_ms","resolution","rating",
           "cast_names","summary","tags","douban_id","playback_state":"playing|paused",
           "position_ms","speed","last_sync_unix_ms"},
  "members": [{"user_id","joined_at","last_seen_at"}],
  "events": [{"id","user_id","event_type","position_ms","speed","payload","created_at"}],
  "last_event_id": 10
}

上报事件 event（POST JSON + CSRF）：

字段类型必填说明
event_typestring是play / pause / seek / speed / leave / voice_offer / voice_answer / voice_candidate / voice_leave / chat_message
position_msint播放事件必填播放位置
speedfloat否0.5-3.0，步进 0.5
client_timestamp_msint否延迟补偿（≤1500ms）

同步建议：每 poll_interval_ms(500ms) 调 poll；偏差超 sync_threshold_ms(1000ms) 对齐；每 heartbeat_interval_ms(2500ms) 心跳。

4.2 withUstrm 媒体库 GET /api/strm.php

需情侣账号（未登录 401）。action 默认 info。内部自动代理 8081 端口媒体库接口，安卓端无需关心内部凭证。

action参数响应
info无{success, data:{serverName, version, baseUrl, authEnabled, supportedMediaTypes}}
counts无{success, data:{total, movie, series}}
mediatype(movie/tv)、keyword、page、pageSize(≤100){success, data:{total, page, pageSize, items:[{id,name,type,mediaType,originalTitle,year,posterUrl,backdropUrl,voteAverage,tmdbId,episodeCount}]}}
detailid(必填){success, data:{id,name,type,...,scrapeStatus,episodes:[{id,episodeNo,sourceFileName,sourcePath}]}}
resolveid(必填)、episode(可选){success, source:"strm", url, type:"m3u8"|"mp4", name}
posters无{success, data:{<mediaId>:"/api/strm.php?action=img&id=N"}}
imgid(必填)image/jpeg 海报
proxyurl(http/https 必填)流式转发（支持 Range）
proxy_m3u8url(m3u8 必填)m3u8 改写为 proxy_seg
proxy_segurl(分片必填)转发 TS 分片（缓存 1h）

4.3 共同观影播放流程（推荐链路）

1. 登录 → 取 csrf_token + Cookie
2. GET /api/desktop.php?action=library 获取媒体列表（items[].id 即 strm 媒体 id）
3. POST /api/watch.php?action=default {"media_id": N} 加入共看房间
4. 轮询 /api/watch.php?action=poll&since=X 同步播放状态
5. POST /api/watch.php?action=event 上报 play/pause/seek/speed
6. 播放地址：GET /api/strm.php?action=resolve&id=N（可带 &episode=M）拿 {url,type}

5. withUstrm 直连服务 API（可选，端口 8081）

仅当需要绕过 PHP 网关直连 withUstrm 后端时使用；普通安卓端推荐走 /api/strm.php 网关。

  • 统一响应 ApiResponse<T> = {"code":200,"message":"...","data":...}，code===200 成功
  • 认证：除标注公开外均需 Authorization: Bearer <JWT>；播放推荐用 X-API-Key 头
  • Swagger：http://host:8081/swagger-ui.html

6. 常见流程示例

6.1 登录并保存 Cookie（OkHttp）

RequestBody body = new FormBody.Builder()
        .add("username", "user1").add("password", "123456").build();
Request req = new Request.Builder()
        .url(BASE_URL + "/api/desktop.php?action=login")
        .post(body).build();
// 使用带 CookieJar 的 OkHttpClient，自动保存 PHPSESSID / withu_device

6.2 带 CSRF 的写请求

// 从 bootstrap/login 响应取得 csrfToken
Request req = new Request.Builder()
        .url(BASE_URL + "/api/like.php")
        .addHeader("X-CSRF-Token", csrfToken)
        .post(jsonBody("{\"target_type\":\"article\",\"target_id\":1}"))
        .build();

6.3 共同观影同步循环（伪代码）

while (true) {
    state = GET /api/watch.php?action=poll&since=lastEventId
    for (event in state.events) {
        switch (event.event_type) {
            play  -> player.play(event.position_ms, event.speed)
            pause -> player.pause()
            seek  -> player.seek(event.position_ms)
            speed -> player.setSpeed(event.speed)
        }
        lastEventId = max(lastEventId, event.id)
    }
    if (localChanged) POST /api/watch.php?action=event {...}
    POST /api/watch.php?action=heartbeat
    sleep(poll_interval_ms)
}
