# withU Desktop Architecture

目标不是“播放器壳”，而是完整的 withU 桌面客户端。

## 分层

- Web 后端：PHP / MySQL，负责账号、情侣空间、媒体库、一起看、聊天、历史和主题配置。
- Windows 原生壳：WinUI 3，负责系统风格页面、登录、设置、壳层导航。
- 播放与高交互页：Qt 6 / QML / C++，负责播放器、全屏浮层、列表、聊天输入、同步控制。
- 解码内核：优先 libVLC，其次 libmpv；后续再按平台补充硬解优化。

## 统一约束

- 所有 UI 共享同一套主题 token。
- 主题必须支持浅色、夜间、樱花粉透玻璃和自定义纯色。
- 播放链路只依赖 OpenList 路径/直链，不依赖服务器 FFmpeg 转码。
- “一起看”同步逻辑必须与网页端保持一致。
