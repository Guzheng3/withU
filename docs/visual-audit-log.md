### 28. 影视库「最近播放」卡片点击后跳回影视库

- 位置：`backend/app/watch.php` 第 62 行附近「最近播放」数据组装。
- 验证：用真实 `watch_history` 数据对照——修复前链接 id 为历史记录 id（25 / 23 / 22 / 21 / 16），修复后为对应媒体 id（21 / 62 / 64 / 62 / 1）；`php -l` 通过，页面其余结构、进度百分比与徽章计算未改动。
- 标签：`recent-rail-link-id-v1`。
